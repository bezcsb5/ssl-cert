## 雨云SSL证书是什么，证书是谁签的

雨云本身不是 CA（证书颁发机构），它做的是中间层：把第三方 CA 的签发流程包进自己的控制台，你在里面选产品、填域名、做验证，签发完成后证书统一存放在"SSL证书中心"。

免费证书这一档的供应商换过。雨云早期公告里说得很直接——证书中心提供 Let's Encrypt 的免费证书，当时已经累计签发 14000 多张。而现在的官方文档和产品列表里，免费证书写的是 **TrustAsia（亚洲诚信）免费 SSL 证书**，类型为 DV、域名类别为多域名、购买时长 3 个月、价格为 0 元。也就是说，免费这条路还在，只是签发机构换成了国内的 CA。

付费部分走两个品牌：GeoSSL 和 TrustAsia，覆盖 DV、OV、EV 三种验证等级，域名类别分单域名、多域名、通配符。

一个容易被误解的点：官方文档明确写了，DV、OV、EV 三种证书在**加密强度上没有差异**，区别只在身份验证等级。所以 OV 贵几十倍，买的不是"更安全"，而是证书里带企业实名信息、审核流程更严。

## 免费证书的申请流程，和两个最容易踩的坑

整个流程官方给的概览就三步：选择证书 → 验证域名所有权 → 下载已签发证书。

**第一步，选证书。** 在证书列表里选证书类型（DV）、域名类别（多域名）、产品名称（TrustAsia 免费 SSL 证书），填上要保护的域名，比如 `rainyun.com`。注意域名购买后不能修改，填之前多看一眼。

**第二步，验证域名所有权。** 这是真正卡人的地方。系统会提示你添加一条 TXT 记录，主机记录格式是 `_acme-challenge.二级部分`——比如申请 `a.abc.com` 和 `b.abc.com`，你要加的是 `_acme-challenge.a` 和 `_acme-challenge.b` 两条，而不是直接加 `_acme-challenge`。这个细节官方在常见问题里专门点出来过，写错了就会一直提示"未成功被证书提供商验证成功"。

如果域名本身就是在雨云注册、并且用的是默认 DNS，可以走自动验证，系统自己加解析记录，官方说明是通常在几分钟内就能拿到完整证书。域名托管在别处，就只能手动加 TXT 记录，加完等 DNS 生效（通常一两分钟到几十分钟不等）再回来点"我已完成解析"。

**第三步，下载。** 签发完成后页面会给出"查看&下载"入口，拿到证书文件和密钥文件，`crt` 给服务器，`key` 自己收好。

## 免费证书够不够用：90 天和多域名限制

免费的那张是 DV 多域名证书，两个限制要提前知道：

**有效期只有 3 个月。** 这是行业惯例，Let's Encrypt 也一样，90 天到期，意味着一年要处理四次续期。

**多域名证书不支持添加通配符域名。** 官方文档写得很清楚：多域名证书只支持添加多个明确域名，不支持再加一个 `*`。所以如果你的站点是 `a.example.com`、`b.example.com`、`c.example.com` 这种不断新增子域名的结构，免费证书要么每次都重新申请列清楚，要么干脆上通配符证书。

这两条决定了免费证书的适用面：个人博客、测试环境、几个固定域名的展示站，够用；域名结构会持续扩张、或者需要给客户证明企业身份的场景，不够用。官方自己的对比表也是这个结论——免费证书适合个人网站、测试环境和轻量级项目，付费证书更适合长期稳定运行的企业官网和电商平台。

## 证书签发之后，怎么真正用起来

拿到证书只是第一步，装上去才是目的。雨云这边有两条路。

**自己的服务器（宝塔、Nginx 等）：** 把证书文件放到服务器上，在面板的 SSL 设置里填入绝对路径，测试配置没问题再 reload。宝塔用户可以直接把证书内容和密钥粘进 SSL 那一栏。

**雨云自家的产品（域名绑定、CDN、对象存储）：** 证书中心是统一管理层，申请或上传的证书可以直接在下拉框里一键选择，不用重复下载上传。

如果你只是想把手里的证书放进雨云统一管理，可以走"我的证书 → 上传证书"，这里要注意格式：必须填 Nginx 格式的证书内容（`.crt`）和密钥内容（`.key`），打开文件全选复制粘贴，别只贴中间一段。

**开启 HTTPS 时有个容易翻车的点。** 在域名管理处勾选"开启 HTTPS 支持"之后，你还必须去 EP 或者宝塔面板里同步开启 HTTPS 并绑定同一张证书。两边不同步，访问时会直接给你 502。同理，"强制 SSL 跳转"这个选项必须建立在已经开启 HTTPS 支持的前提下，它的作用是让 `http://` 自动跳到 `https://`。

## 想省掉三个月一次的续期：用 API 做自动化

免费证书 90 天一轮，手动续太累，但确实有更省事的做法。

雨云提供域名解析的 API 能力，开源 ACME 客户端 **lego 从 v4.21.0 开始内置了 rainyun Provider**（代码标识就是 `rainyun`）。配好一个环境变量 `RAINYUN_API_KEY`，就能走 DNS-01 挑战自动签发包括通配符在内的证书：

bash
RAINYUN_API_KEY="xxxxxxxxxxxxxxxxxxxxx" \
lego run --dns rainyun -d '*.example.com' -d example.com


凭据也可以写成文件，用 `RAINYUN_API_KEY_FILE` 指向路径，适合放在 CI 或容器环境里。

这件事的实际意义不止是省手动操作：**通配符证书只能用 DNS-01 验证**，没法用文件验证。所以如果你想要 `*.example.com` 这张证书，要么在控制台手动加 TXT 记录，要么用 lego 这类工具接上雨云 API 自动完成。1Panel 社区也已经提过对接雨云 DNS 做证书自动申请的需求，官方回复是等 lego 发版后接入——现在 lego 那边已经发布，支持这个 Provider 的面板工具会越来越多。

## 几个高频问题

**验证一直提示失败怎么办？** 先确认三件事：TXT 记录的主机记录名写对了没有（要带二级部分）、解析是否已经生效、记录值有没有多粘贴空格或换行。DNS 未生效是最常见的原因，等几分钟再点一次验证，别急着重新申请。

**免费证书能用在微信小程序上吗？** 小程序要求服务端 HTTPS 且证书链路完整可信，免费 DV 证书本身是可信 CA 签发，正常使用没有问题。真正需要注意的是别把证书链截断，只贴了叶子证书。

**付费证书和免费证书，浏览器表现有区别吗？** 从加密角度看，官方文档已经说明 DV/OV/EV 加密强度一致，地址栏安全锁都一样。付费买到的是身份验证等级、签发时效和域名覆盖形式（通配符、多域名），不是"更强的加密"。

**证书到期前有没有提醒？** 雨云证书中心会在列表里显示最近的申请记录，且有过"7 天内的申请可以发起重新验证"的机制，方便你重签而不是从零再来一次。周期性的续期提醒和自动续期能力在证书中心里配置，具体以当前控制台显示为准。
